

# Change Font to Manrope

## Overview
Replace Inter with Manrope as the primary site font.

## Changes

### 1. `index.html`
- Update the Google Fonts link from `Inter:wght@100..900` to `Manrope:wght@200..800`

### 2. `tailwind.config.ts`
- Replace `"Inter"` with `"Manrope"` in both the `sans` and `display` font family arrays

No other files need changes.
